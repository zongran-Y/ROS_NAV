# Optional Gazebo Fuel model

The upstream standing-person model files are not included in this repository. The simulation image can use them when they are placed in this directory before building `Dockerfile.simfinal`.

Source: [Gazebo Fuel: Standing person](https://fuel.gazebosim.org/1.0/OpenRobotics/models/Standing%20person/1)

Review the upstream terms before downloading, using, or redistributing the mesh and texture files. Keep this instruction file; model assets are ignored by Git.
